# :rocket: SailPoint Campaign Report Automation

## :pushpin: Overview
A Python-based automation framework designed to streamline **SailPoint IdentityIQ certification campaign reporting and audit evidence collection**.

The project uses **SailPoint REST APIs** to extract certification campaign data, process multiple report formats (CSV, PDF, ZIP), and automatically organize audit-ready artifacts. It also integrates with **Jira workflows** to attach certification evidence for compliance tracking.

This solution reduces manual effort in Identity Governance (IGA) reporting and improves audit readiness and consistency.

---

## :dart: Key Features
- Automated extraction of SailPoint IdentityIQ certification campaign data using REST APIs
- Processing of campaign reports in CSV, PDF, and ZIP formats
- Automated packaging and organization of audit evidence
- Multi-campaign report consolidation and standardization
- Jira integration for attaching audit and certification evidence
- Structured compliance-ready reporting workflow
- Reduced manual intervention in IAM certification processes
